TSP ENERGY SOLAR · PRIMEIRO ACESSO

Uma base segura para começar.

Configure o projeto tsp-energy no plano gratuito Spark. Este guia não altera seu projeto automaticamente.

1. Criar seu acesso

  1. No console Firebase, abra Authentication → Método de login.
  2. Ative E-mail/senha. Não é necessário ativar login por SMS.
  3. Em Usuários → Adicionar usuário, crie seu acesso e copie o UID. Defina a senha diretamente no console; nunca salve senhas no Firestore.

2. Criar o banco e autorizar a conta

  1. Abra Firestore → Criar banco de dados → Standard, ID (default).
  2. Escolha a região com cuidado; ela é permanente. Para operação no Brasil, São Paulo é uma opção.
  3. Comece em modo de produção, com acesso bloqueado.
  4. Crie a coleção admins e um documento cujo ID seja exatamente o UID da conta.
  5. Adicione o campo active, tipo boolean, valor true.
  6. Publique as regras do arquivo firestore.rules entregue com o projeto. O login sozinho não libera acesso sem essas regras.

Para revogar um administrador, altere active para false no console. A aplicação não permite conceder privilégios.

3. Cadastrar a empresa

  1. Entre no aplicativo e abra Configurações.
  2. Selecione Importar configurações e escolha o arquivo privado configuracoes-iniciais.json, fornecido separadamente do site.
  3. Revise os dados transcritos do modelo da fatura. Complete endereço, cidade, textos e dia de vencimento.
  4. Se desejar, selecione logotipo e QR Code fornecido pelo banco. Confira a imagem no aplicativo bancário.
  5. Clique em Salvar configurações e aguarde a confirmação do Firebase.

O arquivo inicial contém informações de pagamento. Não o envie ao GitHub nem o coloque na pasta pública do site.

4. Domínio, publicação e cópias

Use Firebase Hosting estático. Em Authentication → Configurações → Domínios autorizados, confira o domínio de produção. Para teste local, adicione localhost e 127.0.0.1 se necessário.

O projeto inclui comandos de compilação, testes e publicação no README. A publicação requer uma conta Firebase autorizada no projeto.

Exporte suas configurações regularmente e guarde as cópias em local privado. O histórico permite baixar as dez versões mais recentes; as anteriores permanecem no banco.

Uso gratuito e conexão

Mantenha o Spark. O aplicativo não usa Cloud Functions, Cloud Storage, envio pago de mensagens ou integração bancária. O Firestore tem cotas; acompanhe a aba Uso no console.

Você precisa estar conectado para autenticar e salvar. Se houver falha, o aplicativo não informa sucesso sem confirmação do servidor. Alterações não salvas podem ser exportadas como rascunho.

Esta entrega corresponde à etapa 2. Clientes, consumos, faturas e pagamentos serão adicionados nas etapas seguintes.
